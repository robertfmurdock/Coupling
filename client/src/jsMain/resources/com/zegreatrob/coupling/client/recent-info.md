### Coupling CLI

Especially in this more automated world, I've added a few more features to the Coupling CLI and have started distributing it on [npm](https://www.npmjs.com/package/@continuous-excellence/coupling-cli).

I'm *sure* it's not sufficient for everyone's needs, so I'd love more feedback on what would be valuable to you!

### ze-great-dashboard

Because so many of the teams I've been working with have been bereft of good build system visibility, I decided to create [ze-great-dashboard](https://github.com/robertfmurdock/ze-great-dashboard) in order to see just how *cheap* and *secure* I could make an open source tool that lets you see a *lot* of status in a small area without losing hours to configuration. Here's the one I'm using to track my open source development [Coupling development dashboard](https://dashboard.zegreatrob.com/). It looks like it costs about 50c a month to host, and is designed to be usable with any OAuth2 system, so if that seems of use to you, try it out!

### testmints-js

I started the testmints side-project back in 2019, and even then I thought to myself "this seems like something that would translate well to many languages-especially languages with sophisticated semantic features".

And with AI, the cost of doing a port and semantic review for additional languages dropped *significantly*. So I've created testmints-js (which is native Typescript) and have been using it extensively when working on ze-great-dashboard, to really kick its tires.
